### Main shortcuts
- Super + Q: close window / close tab
- Super + Space: open the search menu
- Super + S: show hidden applications
- Super + Shift + S: hide hidden applications

### Extra useful shortcuts
- Super + Enter: open terminal
- Super + Shift + Q: quit app
- Super + Arrow Keys: move focus
- Super + Shift + Arrow Keys: move window
- Super + F: fullscreen
- Super + D: fit screen
- Super + L: lock screen
